# 도면 개정 자동 비교 도구 — 성과 요약 (v0.9.2-internal)

## 무엇을 하는 도구인가

이전/개정 도면(DWG·DXF·PDF)을 자동 비교해 **변경 구역을 구름마크로 표시**하고,
변경 대장(xlsx)·구름마킹 DXF를 자동 생성하는 검토 보조 도구.

## 핵심 수치 (전부 실도면 실측)

| 항목 | 수치 |
|---|---|
| 비교 소요 시간 | 대형 상세도 쌍 기준 **~31초** (초기 버전 대비 2.7× 단축) |
| 가짜 변경 자동 제거 | 재작도(재원점) 도면에서 **2,886건의 허위 '수정' 자동 식별·제거** (실측) |
| 화면 반응 | 팬/줌 **21× 경량화** — 10만 선분 도면에서도 즉답 |
| 변경 표시 | 구역별 구름마크(삭제·추가·수정·이동 색 구분) + **묶음 이동 자동 추정**(이동 전→후 양화면 표시) |
| 최신 DWG 호환 | AC1032(AutoCAD 2018+) 자동 변환 — DWG를 그대로 입력 (ODA 설치 PC, 설정 불필요) |
| 산출물 | 구름마킹 DXF · 변경 대장 xlsx · 변경 구역 CSV · 요약 브리핑 자동 생성 |
| 품질 기반 | 자동 테스트 **3,900+ 전체 통과**, 합성 골든 도면 15쌍 정확도 기준선 측정 운영 |

## 검토 업무에 주는 효과

1. **개정 검토 진입 시간 단축**: 변경 위치 수색(도면 전체 육안 대조) → 31초 자동 + 구역 리스트 클릭
2. **누락 위험 감소**: 사람 눈이 지나치기 쉬운 소규모 변경(치수·태그·블록 내부)도 구역으로 승격
3. **기록 자동화**: 변경 대장·구름마킹 도면이 비교 즉시 생성 — 회람/보고 양식에 바로 활용

## 정직한 한계 (파일럿 운영 원칙)

- **보조 도구**: 미검출 가능성에 대한 정량 검증(실도면 ground-truth)은 파일럿과 병행 축적 중.
  최종 판단·승인은 검토자가 수행.
- 사외 반출 금지(기밀·구성요소 라이선스).

## 파일럿 계획

- 1주차: 2~3명 배포 → 실사용 피드백/로그 수집 → 주간 패치
- 지표: 사용 건수, 검토 시간 체감, 누락/오탐 사례(=정확도 데이터로 축적)
