# 도면 변경 비교 워크벤치 — 사내 파일럿 사용 가이드 (v0.9.2-internal)

> **이 도구는 도면 개정 검토를 *보조*하는 도구입니다.** 변경 후보를 자동으로 찾아 보여주지만,
> 최종 판단과 승인은 반드시 검토자가 합니다. (검출 누락 가능성에 대한 정량 검증이 진행 중입니다)

## 1. 설치 (1분)

1. 배포 zip을 원하는 폴더에 압축 해제 (예: `C:\Tools\DrawingCompare\`)
2. **`DrawingCompare_실행.bat`** 더블클릭 → 워크벤치 창이 뜨면 끝
3. 요구사항: Windows 10/11. 별도 설치 불필요.
   - **ODA File Converter**(무료)가 설치된 PC에서는 최신 버전 DWG(AC1032 등)를
     그대로 넣어도 **자동 변환**됩니다 — 별도 설정 없이 설치만 돼 있으면 동작하며,
     설정 메뉴 "DWG 자동 변환"에서 끄고 켤 수 있습니다.
   - ODA가 없는 PC에서는 안내 메시지의 다운로드 링크로 설치하거나, CAD에서
     DXF(R2018)로 변환해 사용하세요.

## 2. 기본 사용 (비교 1회 ≈ 30초)

1. 좌측에서 **이전 도면**과 **개정 도면**(DWG/DXF/PDF) 선택 — 파일 또는 폴더
2. **비교 실행** → 약 30초 내 완료 (대형 도면 기준)
3. 우측 **변경 구역 리스트**(C-001, C-002…)를 클릭하면 양쪽 화면이 해당 위치로 이동

## 3. 화면 해석

| 표시 | 의미 |
|---|---|
| 🔴 빨간 구름 | **삭제됨** — 이전 도면에만 있는 요소 |
| 🟢 초록 구름 | **추가됨** — 개정 도면에만 있는 요소 |
| 🟠 주황 구름 | **수정됨** — 내용/치수가 바뀐 요소 |
| 🔵 파란 구름 | **이동됨** |
| 📦 "묶음 이동(추정)" 배너 | 삭제+추가 쌍이 사실은 **한 묶음이 통째로 이동**한 것으로 추정됨. 이때 좌측 화면=이동 전 위치, 우측 화면=이동 후 위치 |
| 상단 안내 배너 | 삭제/추가 요소의 의미를 설명 (반대편 도면에 대응 요소가 없는 것이 정상) |

- 화면은 항상 **좌 = 이전 도면, 우 = 개정 도면**이며 같은 좌표를 동기화해 보여줍니다.
- 구역 클릭 시 주변 도면이 함께 보이도록 적당히 줌됩니다. 선택한 변경에는 구름마크가 항상 선명하게 표시됩니다.
- 첫 구역의 고해상도 렌더는 15~30초 걸릴 수 있습니다(화면 안내 표시). **같은 도면의 다음 구역부터는 ~4초**입니다.

## 4. 산출물 (보고서/CAD 반입용)

비교가 끝나면 결과 폴더(`내문서가 아닌 %LOCALAPPDATA%\DrawingCompareWorkbench\runs\compare_날짜_시각\`)에 자동 저장:

| 파일 | 용도 |
|---|---|
| `artifacts/cloud_marked/*_after_marked.dxf` | **구름마크가 그려진 DXF** — CAD에서 바로 열람 |
| `artifacts/change_register.xlsx` | 변경 대장 (구역별 목록) |
| `artifacts/change_zones.csv` | 변경 구역 데이터 |
| `artifacts/drawing_change_brief.md` | 요약 브리핑 |

## 5. 알려진 한계 (정직 고지)

1. **보조 도구입니다** — 미검출 가능성이 있으므로 도장/승인 전 최종 육안 검토는 필수입니다.
2. DWG 네이티브 직독은 AC1015(R2000) 범위입니다. 그 외 버전은 ODA 자동변환(설치된 PC에서 기본 동작) 또는 사전 DXF 변환으로 처리됩니다.
3. 회사 외부로 도구/결과물을 반출하지 마세요 (기밀 + 구성요소 라이선스).
4. 도면이 매우 클 때 배경 래스터가 일부 흐리게 보일 수 있습니다(벡터 구름/마커는 항상 선명).

## 6. 문제가 생기면

- 프로그램 폴더의 `logs\error_YYYYMMDD.log` 와 `logs\fault_*.log` 를 첨부해서
  **배포 담당자에게** 전달해 주세요. (재현 화면 캡처가 있으면 더 좋습니다)
- 비교 결과가 이상하다고 느끼면: 해당 **구역 번호(C-xxx)** 와 "무엇이 이상한지" 한 줄이면 추적에 충분합니다.
