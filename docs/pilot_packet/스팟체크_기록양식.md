# 사내 파일럿 — 스팟체크 집계 양식 (여러 쌍)

> 비교마다 결과 폴더에 **`pilot_spotcheck.md`가 자동 생성**됩니다(쌍별 검출표 + 작성칸). 이 파일은
> 여러 쌍을 돌렸을 때 **한눈에 집계**하기 위한 보조 양식입니다 — 1차 작성·반송은 각 쌍의
> `pilot_spotcheck.md`로 하세요(사용가이드 5장).

## 판정 기준 (배포 가/부)

- **배포 진행**: 아는 변경의 검출 누락 0건 + 위치 오류 0건 (가짜 변경 소수는 허용 — 보조 도구 고지로 커버)
- **보류·수정 후 재시도**: 아는 변경 누락 1건 이상 → 해당 쌍과 누락 내용을 개발 담당에게 전달 (구역 번호/위치/내용)

## 기록 후

- 작성한 각 쌍의 `pilot_spotcheck.md`(+이 집계표)를 배포 담당에게 반송
- 누락/오탐 사례는 그대로 ground-truth 라벨로 축적 (향후 정량 검증 입력)
