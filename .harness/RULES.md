# RULES — 핵심 제약 (경량화)

> ⚠️ 이 목표(재현 가능 패킷 빌더 + 자동시트 가이드)에 직결되는 조항만.

## 절대 규칙 (위배 시 작업 중단)
- **exe 빌드 안 함**: 스크립트는 **빌드된 app-dir를 입력**받아 조립만. PyInstaller 호출 0(범위 밖·빌드머신).
- **버전관리 소스**: 가이드 등 패킷 소스는 `docs/pilot_packet/`(추적). `release/`(gitignore)에 소스 두지 않음. 패킷 산출물만 release/.
- **자동시트 정직**: 가이드는 `pilot_spotcheck.md`가 **비교 완료 시 자동 생성**됨을 정확히 기술 + **작성·반송** 지시. 빈 수기 양식으로 되돌리지 않음. 인간 dry-run OPEN 유지.
- **정책 준수**: 패킷/가이드 텍스트는 `cad_policy_gate` 그린(DWG "완전지원"·ODA "필수" 미주장). v0.9.2 통과 문구 보존.
- **재현성**: 매니페스트(버전·git sha·내용)로 패킷 출처 추적. 수동 단계 0(스크립트가 전부).

## 설계/코드 제약
- 경량: argparse + 파일 복사/쓰기 + zip. 무거운 의존 금지.
- 테스트는 결정적·stub app-dir(실 exe 불요). per-PR 목록 추가.
- 샘플 쌍은 합성 골든 DXF만(기밀/라이선스 안전).
- 한 반복 = 한 단계.

## 우선순위 (충돌 시)
1. 정직성(자동시트 정확·exe 빌드 안 함) > 2. 재현성(수동 0) > 3. 정책 준수 > 4. 결정성 > 5. 단순성

## 검증 연결
- 조립·샘플 = T-PK1/T-PK3. 가이드 = T-PK2. 재현·결정 = T-PK4. vapor·dogfood·gate = T-PK5.
